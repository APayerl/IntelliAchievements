# IntelliAchievements
This plugin adds some fun during coding. Allows you to get and check achievements for writing and running your Java programs, or using your IDE User Interface. 

## Description
This plugin allows you to earn achievements during code. To use it, simply, download and write code. All your progress is saved. You can check it in Settings.
